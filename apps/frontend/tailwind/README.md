# Phase 1 - Step 2: Tailwind CSS Exercises

## Task

Create a modern Spider-Man profile card using **Tailwind CSS**.

## Exercise – Spider-Man Card

* File: `spiderman-card.html`
* Includes:

  * Circular profile image (`images/spiderman-image.jpg`)
  * Name (`<h1>`), quote, and short bio (`<p>`)
* Styled with **Tailwind classes only**:

  * Gradient background, blur effect, shadows, borders, spacing, colors
* Layout: centered flexbox card, responsive width

## Notes / Learning

* Practiced **utility-first styling** with Tailwind.
* Added **comments in HTML** explaining each element and styling.
* Maintained **accessibility** with `alt` text.
* Kept assets organized in `images/` folder.
